# MVP 수익 모델 초안

작성일: 2026-11-18

## 1. 기본 원칙

- 기본 플레이는 무료로 유지한다.
- 유료는 선택형 편의, 외형, 성장 보조에 집중한다.
- pay-to-win를 피하고, 핵심 재미는 무료 유저도 누릴 수 있게 설계한다.
- Roblox 특성상 개발자 상품(Developer Product), 스킨, 패스형 구독이 가장 현실적이다.

## 2. 추천 수익 구성

### 2.1 무료 플레이

- 기본 택시 운전 루프
- 기본 차량 사용
- 기본 배차/손님 수락
- 기본 도시/지역 일부 접속
- 기본 성장 시스템

무료 유저는 플레이 자체가 충분히 재미있어야 한다.

### 2.2 유료 상품

1. 차량 스킨 팩
   - 목적: 가장 안전한 수익원
   - 예시: 기본 차량 외형 변경, 색상 패키지, 휠/범퍼/라이트 스타일
   - 권장 가격: 50~300원대

2. 면허 / 업무 패키지
   - 목적: 실제 게임 루프와 연결되는 보상
   - 예시: 초급 면허, 특별 업무 Unlock, 시작 보너스 패키지
   - 권장 가격: 200~800원

3. 성장 보조 팩
   - 목적: 빠른 진입과 편의 제공
   - 예시: 시작 자금 보너스, 경험치 배율, 짧은 시간 보조
   - 권장 가격: 200~1200원
   - 주의: 게임 자체를 쉽게 바꾸지 않도록 제한한다.

4. VIP / Taxi Pass
   - 목적: 월간 안정 수익 확보
   - 예시: 일일 보상 증가, 스킨 잠금 해제, 보너스 소득
   - 권장 가격: 700~2000원
   - 주의: 혜택은 강하지 않게 설계한다.

5. 한정 이벤트 스킨 / 시즌 패키지
   - 목적: 희소성, 시즌성, 반복 구매 유도
   - 예시: 한정 스킨, 이벤트 배지, 시즌 보상
   - 권장 가격: 300~800원

## 3. 추천 상품 조합

### MVP 안

- 무료: 기본 택시 운전 + 기본 차량 + 기본 배차
- 유료:
  - 차량 스킨 팩
  - 면허 패키지
  - 성장 보조 팩
  - VIP 패스
  - 한정 이벤트 스킨

이 조합은 가장 무난하고, 유저가 과금하더라도 게임 흐름을 크게 훼손하지 않는다.

## 4. 가격 전략

| 구분 | 추천 가격대 | 비고 |
| --- | ---: | --- |
| 소액 상품 | 50~300원 | 가장 쉽고 무난하게 구매 유도 |
| 중가 상품 | 300~800원 | 비즈니스 루프와 연결됨 |
| 성장 보조 | 500~1200원 | 유저 가치가 분명함 |
| VIP | 700~2000원 | 월간 안정화 용도 |
| 이벤트 한정 | 300~800원 | 시즌성 유지 |

초기에는 너무 비싸지 않게 잡는 것이 중요하다. 초반 전환율을 높이기 위해 소액 상품 위주로 시작하는 것이 좋다.

## 5. 피해야 할 구조

- pay-to-win 구조
- 너무 많은 유료 상품
- 무료 유저에게 핵심 재미를 빼앗는 구조
- 무조건적인 월 구독만 고집
- 과도한 가격 정책

## 6. 수익 루프 설계

좋은 수익 루프는 다음 흐름으로 이루어진다.

1. 유저가 게임에 재미를 느낌
2. 운전/배차/업적 루프를 반복함
3. 차량 외형, 면허, 성장 보조에 욕구가 생김
4. 유료 상품을 구매
5. 더 많은 콘텐츠를 경험하고 유지율이 상승
6. 시즌 이벤트와 한정 스킨으로 반복 구매 유도

즉, 돈을 내는 이유는 게임 루프 안에 자연스럽게 포함되어야 한다.

## 7. 최종 추천안

이 프로젝트의 최종 추천 MVP 수익 모델은 다음과 같다.

- 기본 플레이 무료
- 유료는 아래 네 가지 축으로 설계
  - 차량 스킨
  - 면허/업무 패키지
  - 성장 보조 팩
  - VIP 패스
- 한정 이벤트 스킨은 추가로 운영
- 처음에는 3~5개 상품만 유지하고, 반응을 보고 추가 확장

이 방식은 Roblox에서 가장 현실적이고, 게임의 재미를 해치지 않으면서도 수익을 만들 수 있다.

## 8. 요약

이 프로젝트는 "유료 게임"보다 "무료 로블록스 게임 + 선택형 유료화" 구조가 적합하다.

가장 현실적인 우선순위는 다음과 같다.

1. 무료 루프 확실하게 만들기
2. 차량 스킨으로 수익 시작
3. 면허/성장 패키지 추가
4. VIP 구독으로 월간 수익화
5. 시즌 제한 스킨으로 희소성 확보

이 구조는 초기 진입장벽이 낮고, 유저 유지와 수익화의 균형이 가장 잘 맞는다.
